¿Para qué sirven?

Para construir un parser descendente LL(1), para cada no terminal el parser tiene que poder decidir qué producción aplicar conociendo sólo el símbolo de preanálisis: el próximo token del flujo de tokens.

Lo podemos pensar como una función:

δ: (NoTerminal, Token) -> Producción a aplicar
  • Si la gramática es LL(1), δ cumple unicidad: para cada par hay una sola producción.
  • Si el par (NoTerminal, Token) no está definido → error sintáctico.
Los conjuntos se calculan una única vez para una gramática. El analizador ya los tiene precalculados y, al leer un token, sabe qué producción aplicar.

Conjunto Primero

Primero(X1...Xn) = los terminales con los que puede empezar lo que se deriva de X1...Xn.
Si X1...Xn puede derivar en ε, ε también va en el conjunto.

Cómo lo calculo

  • Si X1 es un terminal → Primero(X1...Xn) = {X1}
  • Si X1 es un no terminal → Primero(X1...Xn) = Primero(X1)
A -> 12BC4

Primero(12BC4) = {1} → empieza con un terminal, listo.

Primero sin conflictos

Para que no haya conflictos, los Primero de los lados derechos de un mismo no terminal tienen que ser disjuntos (sin tokens en común).

Primero(prod. 1) ∩ Primero(prod. 2) = ∅     (para cualquier par de producciones)

Ejemplo

A -> 1234 | B235 | C112 | 237
B -> 5 | 41
C -> 21 | 25 | 3
  • Primero(1234) = {1}
  • Primero(B235) = Primero(B) = {4, 5}
  • Primero(C112) = Primero(C) = {2, 3}
  • Primero(237) = {2}

¿Hay conflicto? Sí → C112 y 237 comparten el token 2.

¿Cómo lo resolvemos? Desagregamos C para verlo mejor:

A -> 1234 | B235 | 21112 | 25112 | 3112 | 237

Y sacamos el 2 como factor común:

A -> 1234 | B235 | 3112 | 2Z
Z -> 1112 | 5112 | 37

Conflicto eliminado. Primero(A) sigue siendo el mismo, pero ahora cada lado derecho tiene un Primero disjunto de los demás.

¿Y si un no terminal puede ser ε?

Si X1 puede generar ε, X1 puede desaparecer. Entonces Primero(X1...Xn) no depende sólo de X1: también depende de lo que viene después de X1.

A eso que viene después lo llamamos Siguiente.

Conjunto Siguiente

Siguiente(A) = los terminales que pueden aparecer justo después de A en las derivaciones. Define el contexto derecho de A. Nunca lleva ε.

Cómo lo calculo

Busco dónde aparece A del lado derecho de las producciones:

  • ...Ax... → A seguido de un terminal → x va al Siguiente(A)
  • ...AB... → A seguido de un no terminal → va Primero(B) sin ε (y si B puede ser ε, sigo mirando lo que viene después)
  • T -> ...A → A es el último símbolo → va Siguiente(T)

Ejemplo

T -> A5
A -> BCD
B -> 1 | 2 | ε
C -> 3 | ε
D -> 3 | 4 | ε

Siguiente(A)? ¿Dónde aparece A? En T -> A5. Después de A viene el 5.

Entonces, Siguiente(A) = {5}

Siguiente(C)? ¿Dónde aparece C? En A -> BCD. Después de C viene D → tomo Primero(D) sin ε = {3, 4}. ¿D puede ser ε? Sí → C queda al final de A, así que también va Siguiente(A) = {5}.

Entonces, Siguiente(C) = {3, 4, 5}

Primero cuando aparece ε

Ahora sí: si X1 puede generar ε →

Primero(X1...Xn) = Primero(X1) U Siguiente(X1)

Si se termina la producción, subo y tomo el Siguiente del no terminal de arriba.

Ejemplo 1

T -> A5
A -> BCD
B -> 1 | 2 | ε
C -> 3 | ε
D -> 3 | 4 | ε

Existe la posibilidad de que A genere (derive) la palabra nula ε.

Primero(T) = Primero(A5) = Primero(BCD) = {1,2} U Siguiente(B)

           = {1,2} U Primero(CD) = {1,2} U {3} U Siguiente(C)

           = {1,2} U {3} U Primero(D) = {1,2} U {3} U {3,4} U Siguiente(A)

           = {1,2} U {3} U {3,4} U {5}

Siguiente(A) = {5}   Primero(T) = {1, 2, 3, 4, 5}

Ejemplo 2

T -> AE8
A -> BCD
B -> 1 | 2 | ε
C -> 3 | ε
D -> 3 | 4 | ε
E -> C | 7
Primero(T) = Primero(AE8) = Primero(BCD) = {1,2} U Primero(CD) = {1,2} U {3} U Primero(D)

           = {1,2} U {3} U {3,4} U Siguiente(A)

Primero(T) = {1,2,3,4} U Siguiente(A) = {1,2,3,4} U Primero(E)

           = {1,2,3,4} U {7} U Primero(C) = {1,2,3,4} U {7} U {3} U Siguiente(E)

Primero(T) = {1,2,3,4} U {7} U {3} U {8}

Primero(T) = {1, 2, 3, 4, 7, 8}

Ejemplo 3

R -> T9
T -> AE
A -> BCD
B -> 1 | 2 | ε
C -> 3 | ε
D -> 3 | 4 | ε
E -> C | 7
Primero(R) = Primero(T9) = Primero(AE) = Primero(A) = Primero(BCD)

           = {1,2} U Primero(CD) = {1,2} U {3} U Primero(D) = {1,2} U {3} U {3,4} U Siguiente(A)

Primero(R) = Primero(T9) = Primero(AE) = {1,2,3,4} U Siguiente(A) = {1,2,3,4} U Primero(E)

           = {1,2,3,4} U {7} U Primero(C) = {1,2,3,4} U {7} U {3} U Siguiente(E)

Primero(AE) = Primero(T) = {1,2,3,4} U {7} U {3} U Siguiente(T) = {1,2,3,4,7} U {9}

Primero(R) = {1, 2, 3, 4, 7, 9}
